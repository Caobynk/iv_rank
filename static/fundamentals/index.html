02黑色系
焦煤 / 焦炭黑色日报 08-20/21
基本面
  • 焦煤供应紧缺：山西安监持续严格、停产产能维持高位、蒙煤通关低位扰动，现货价格涨势迅猛

钢材 / 铁矿黑色日报 08-20/21 + 策略
基本面
  • 钢材淡季需求未显著回暖，制造业补库与建材季节性回升预期存在；铁水产量回升、钢厂亏损扩大
  • 铁矿到港波动剧烈但短期供应压力不突出，铁水负反馈预期证伪；废钢受极端天气影响到货减少
  • 热卷基本面优于螺纹，短期库存压力尚可
行情展望
  • 螺纹处于 3000 元/吨成本关口，预计全年 2900-3300 元/吨箱体弱势震荡，"低趋势、高拉锯"；期权 IV 低位、PCR 高位回落
风险提示
  • 钢厂亏损扩大压制复产；终端需求超预期走弱；铁矿到港大幅回升
03能源化工
原油 / 成品油能源日报 08-20/21
基本面
  • 中东地缘未见缓和：美伊持续对抗、阿联酋遭弹道导弹袭击，美国宣布切断与伊朗一切经济联系
  • 原油升至近一个月高位；美国柴油裂解价差超 100 美元/桶创历史纪录，成品油强于原油

  • 地缘缓和油价快速回落；全球需求走弱；海峡通行恢复
甲醇 / 聚酯 / 烯烃化工日报 08-20/21
基本面

基本面
