库存×利润四象限低库存+低利润=做多窗口、低库存+高利润=趋势中段、高库存+高利润=空头黄金位、高库存+低利润=磨底——定位每个品种当前所处象限
双锚结构两步法先看远期锚位移（供给侧结构变化→交易方向），再看现货相对锚偏离（库存松紧→入场节奏与止盈止损）
行情反转三信号价格高位/低位 + 基差修复后须谨慎；日内频繁升贴水转换；持仓量大幅下降——任一出现即警惕反转
持仓拥挤度净多单率高 + 价格高位 = 行情将结束；配合"增仓上行→价格反推"的拥挤度反转信号识别离场时点
期限结构力学便利收益驱动 Back、Full Carry 钳制 Contango；形态相同内涵不同——须看结构背后的供需各自变动方向，而非只看 Back/Contango 形态
期权风控体系对冲=时间换波动率；gamma/vega 双波动率风险；IV 低位宜买方博凸性、组合控风险；卖方注意保证金与流动性纪律、地缘/政策事件为最大尾部风险
本周商品市场全景：地缘缓和信号初现，天气行情集体降温总览
当前交易的矛盾中心
  • 地缘供给收缩（多） vs 缓和信号初现（空）：按双锚结构——远期锚=美国制裁伊朗约 60 实体（石油收入网络+影子船队）、霍尔木兹低通行量支撑供给收缩叙事；但 8/26 市场开始定价"缓和"——美国最早本周派外交官赴中东、巴基斯坦斡旋，原油应声回落，短期锚（地缘溢价）松动，多空叙事正切换
  • 贵金属债务主线（多） vs 高位获利了结（空）：公共债务突破 40 万亿美元 + 财政部扩大长债回购弱化美元信用（远期锚趋势向上），但 8/26 金银创阶段新高后回落、PCE 与沃什讲话前情绪谨慎（短期锚=利率与数据扰动），短线进入方向选择
  • 天气行情 vs 降温证伪：厄尔尼诺炒作点燃橡胶、棕榈油、棉花、豆一（多为低库存/供应刚性象限），但 8/26 商品多头情绪整体降温——橡胶回落、棉价减仓回调、油脂弱势调整、生猪供增需弱下跌，按反转三信号"价格高位 + 减仓"组合已现，天气溢价进入回吐期
  • 碳酸锂强现实 vs 供应预期反复：按产业链定价权框架——碳酸锂货权在矿山端（枧下窝复产节奏），中游库存/表需只是结果；8/24 环评征求意见稿、8/25 盘中跌超 5%、8/26 领跌新能源金属，供应叙事主导波动、多空切换极快
跨品种统一风控提醒
  • 能源链进入"溢价回吐"敏感期：按双锚结构，地缘溢价属短期锚、回吐速度远超基本面调整速度；美派外交官、巴基斯坦斡旋等缓和信号已现，原油及油化工链（LPG/沥青/燃油/甲醇/烯烃）多单须设硬止损、勿恋战
  • 天气炒作品种防拥挤度踩踏：按持仓拥挤度信号，净多单率高 + 价格高位 = 行情将结束；橡胶/棕榈油/棉花/豆一已现"高位 + 减仓"苗头——反转三信号中的"持仓量大幅下降"一旦确认即离场，勿在急跌中抄底抢反弹
  • 贵金属勿追高、等指引：PCE 数据与央行年会讲话落地前方向不明；期权端 IV 25% 中枢震荡，买方注意时间价值损耗（对冲=时间换波动率），追涨面临小幅回调波动、回调分批优于追涨
  • 黑色需求未验证勿抢跑 + 碳酸锂波动剧烈：旺季需求成色未验证前，钢厂亏损扩大 + 成本托底博弈下波动放大、杠杆不宜过重；碳酸锂供应预期反复单日波动超 5%，按期权风控纪律——情绪行情中仓位控制优先、防止单日大幅回撤
01贵金属
黄金 / 白银贵金属日报 08-19/20/21/25/26 + 周报 08-23 + 期权周报 08-22 + 专题 08-19
基本面梳理
  • 美债信用风险担忧延续（公共债务突破 40 万亿美元），财政部扩大长债回购提振流动性但弱化美元信用，美元指数走弱；7 月 CPI/PPI 延续回落、零售月率意外负增长，加息预期降温
  • 债务担忧与利率回落共振推动金银大涨、黄金一度突破 4500 美元；8/26 金银创阶段新高后回落、弱势调整（白银回调幅度大于黄金），PCE 数据与沃什讲话落地前市场情绪谨慎；期权 IV 围绕 25% 中枢震荡、价波同升有限
矛盾中心
  • 债务信用风险（多） vs 30 年美债利率近 20 年高位（空）：按双锚结构——远期锚=财政信用 + 去美元化（趋势向上、主导中期方向），短期锚=长端利率与数据扰动（决定入场节奏）；两股力量对冲决定短线方向
  • 宏观共振 vs 微观结构：宏观面利率回落 + 债务担忧同向，期权市场 Delta/Gamma/Vega 曾共振指向上行；但 IV 25% 中枢下价波同升有限——按期权风控体系，此时追买波动率溢价不划算
展望与投资建议
  • 债务风险主线支撑黄金中期强势未改，短线转高位调整；牛市价差策略继续验证有效——用买方结构表达方向（IV 中性下以时间价值换凸性）、组合控风险
  • 等待 PCE 数据与央行年会讲话给出方向指引后再加仓；白银弹性大于黄金，金银比回落可考虑多银空金配对；回调至关键均线位分批优于追涨
风控提醒
  • PCE 超预期或沃什偏鹰将引发回调；30 年美债利率高位、长端利率上行短线扰动金银——按反转三信号，价格已在高位、事件落地前勿追高
  • 期权端：IV 25% 中枢震荡、买方注意时间价值损耗；高位波动加大，仓位控制优先；若追涨须以小仓位 + 宽止损应对回调波动
铂金 / 钯金贵金属日报 08-19/20/21/25/26 + 周报 08-23 + 异动快评 08-21
基本面梳理
  • 长端利率回落 + 美元指数走弱，宏观定价环境对贵金属友好，铂钯延续强势运行；8/25 铂金主力收 455.65 元/克（-1.53%）、钯金 317.65 元/克（-1.69%），高位震荡运行
  • 仓单环比回落：铂仓单 5,123 手（环比 -32）、钯仓单 5,447 手（环比 0）——按期限结构视角，仓单回落是现货偏紧的微观确认，但绝对仓单水平仍偏高、对上方构成约束
矛盾中心
  • 贵金属配置需求（多） vs 汽车催化剂需求走弱（空）：铂金受益氢能与工业需求叙事、钯金受燃油车电动化替代压制，两者基本面分化（同属贵金属、驱动不同源）

展望与投资建议

风控提醒
  • 利率预期反复是主要扰动；钯金受汽车尾气催化剂需求走弱压制，单边多钯逻辑不成立

02黑色系
焦煤 / 焦炭黑色日报 08-19/20/21/25/26 + 黑色金属周报 08-23 + 国际化日报 08-25
基本面梳理
  • 焦煤受山西安监严格、蒙煤通关受限及海运煤到港减少影响，现货货源紧缺、价格涨势迅猛，为黑色板块提供成本支撑；但复产预期升温叠加市场畏高情绪，盘面高位震荡
  • 焦炭二轮提涨落地，然成本上涨更快、焦企利润持续承压，供应环比收缩；铁水产量高位回落
矛盾中心
  • 原料紧缺（多） vs 复产预期（空）：按库存×利润四象限——焦煤低库存 + 现货紧缺 + 上游高利润 = "低库存高利润"趋势中段象限（做多窗口已过半）；复产预期升温 + 畏高情绪 + 铁水高位回落，上方空间受限，从单边上涨转入高位震荡
  • 焦炭提涨 vs 成本侵蚀：按产业链利润分配框架，焦炭处于"成本上涨更快、利润被两头挤压"位置——提涨速度能否跑赢成本决定焦化利润修复成色，产业链利润在再分配
展望与投资建议
  • 焦煤强势引领板块上行但上方遇阻，旺季需求成色待验证；按反转三信号"价格高位 + 基差修复后须谨慎"——安监政策未见松动前，回调做多优于追高
  • 关注焦化利润修复：若提涨持续落地、多焦炭空焦煤的利润头寸有兑现空间（需跟踪提涨节奏与落地速度）
风控提醒
  • 复产预期兑现、安监/通关政策边际放松是焦煤最大下行变量（供给侧边际反转）；终端需求季节性回暖不明显压制板块高度
  • 铁水高位回落背景下，成本推升行情对需求端高度敏感——出现钢厂减产加速迹象须及时减仓（负反馈随时切换多空逻辑）
钢材 / 铁矿黑色日报 08-19/20/21/25/26 + 周度策略 08-23 + 铁矿发运数据 08-21 + 期权工具箱 08-20 + 国际化日报 08-21
基本面梳理
  • 钢材端受炉料成本支撑，但表需季节性好转特征不明显、下游对高价资源接受有限，钢价高位震荡；铁水高位回落、钢厂亏损扩大制约复产空间，热卷基本面优于螺纹
  • 铁矿短期供应压力暂不突出、全球发运窄幅波动处历年同期中位，中长期供需宽松预期未改；螺纹 3000 元/吨成本关口，全年 2900-3300 箱体弱势震荡
矛盾中心
  • 炉料成本托底（多） vs 需求疲软（空）：按估值×驱动矩阵——螺纹估值（利润低 + 3000 成本支撑=偏低估）、驱动（需求未验证=中性偏弱），估值与驱动不共振，箱体震荡格局难破；铁矿按大品种看需求的路由规则，中长期供需宽松预期压制
  • 钢厂亏损扩大 = 高成本 + 低需求挤压利润，按产业链利润分配框架，若亏损引发超预期减产，原料端将从支撑转为拖累——多空逻辑随时切换
展望与投资建议
  • 炉料成本托底与需求疲软博弈、高位震荡；关注合金下行与螺纹反套机会（周度策略）
  • 螺纹期权 IV 低位、单边趋势性价比低（按期权风控体系：IV 低位宜买方博凸性）：以虚值期权低成本表达方向 + 价差/跨式组合控风险，替代裸单边（期权工具箱）
风控提醒
  • 钢厂亏损扩大压制复产、亏损加深引发减产负反馈则原料快速回落；终端需求超预期走弱；铁矿到港大幅回升打破平衡
  • 箱体震荡格局追涨杀跌双输（估值驱动不共振、无趋势），注意 2900/3300 箱体边界假突破风险

03能源化工
原油 / 成品油能源日报 08-19/20/21/25/26 + 周报 08-23 + 月度策略 08-24 + 数据/快评 08-20/21/24/25 + 点评 08-21 + 专题 08-19

  • 美国制裁伊朗约 60 个实体（石油收入网络 + 影子船队）、威胁"前所未有的经济孤立"，油价升至近一个月最高水平；8/26 市场再次期待地缘缓和（美国最早本周派外交官赴中东、巴基斯坦斡旋），原油跌幅扩大
  • 成品油强于原油：美国柴油裂解价差超 100 美元/桶创历史记录；沙特发运低位（8/12-21 日均 260 万桶/日 vs 7 年均 458 万桶）；Kpler 库存结构分化、整体去库为主；中国炼厂负荷延续回升
  • 三大机构月报：中东复产预期后延、需求预期小幅下调
矛盾中心
  • 地缘供给收缩（多） vs 缓和信号初现（空）：按双锚结构——远期锚=制裁收紧供给（趋势支撑），短期锚=地缘溢价（波动主导）；缓和信号令短期锚开始反转，多空叙事切换中

展望与投资建议
  • 地缘溢价短期难消退但波动加大，谈判进展是油价下行触发点；下半年旺季来临、全球柴油偏紧格局难见缓解
  • 策略优先级：多裂解价差/成品油 > 多原油单边；单边多原油以地缘事件为交易主轴、事件兑现即离场（事件驱动交易：触发即走，不恋战）
风控提醒
  • 地缘缓和是最大尾部风险：按期权风控体系"vega 含尾部信用风险"——地缘溢价的回吐速度远超基本面调整速度（短期锚反转快于远期锚），美伊谈判进展或海峡通行恢复将引发油价快速回落，多单须设硬止损
  • 商业原油累库与需求走弱构成中期压制；EIA 数据发布日波动放大，仓位与止损提前规划
甲醇 / 聚酯 / 烯烃化工调研 08-18/21/25 + 周报 08-23 + 国际化日报 08-26
基本面梳理
  • 伊朗货源进口减量，MTO 工厂采购转向国产煤制 + 非伊进口的多元化渠道，各渠道精炼甲醇品质无明显差异
