数据来源：OI/行权价/最痛点复用「商品期权成交持仓分布及最痛点位绘制」项目的历史数据；标的价 S 与 IV 由各交易所官方每日行情实时抓取（历史交易日、非盘中实时）。
口径：call 贡献 +、put 贡献 −（标准 Gamma Flip 分解）；净 GEX > 0 表示做市商净多头 gamma（稳定/均值回归），< 0 表示净空头（趋势/放大波动）；零界点即 Gamma Flip。单合约 GEX = Γ·OI·合约单位·S²/100（商品=期货期权，r=0 时 Black-76 gamma 与 BS 同形，T=真实到期日/365）。
状态分类用无量纲归一化 norm = net/(|Σcall|+|Σput|) ∈ [-1,1]（与合约乘数/尺度无关，跨品种可比）：norm > +0.05 → LONG_GAMMA（震荡），norm < -0.05 → SHORT_GAMMA（趋势），其间 NEUTRAL。 真实取值：① 标的价格 S = 各月标的期货结算价（期货每日行情，自动取值）；② IV = 各期权结算价经 Black-76 反解（逐行权价，形成波动率微笑；反解失败依次回退交易所公布IV→该月ATM IV→20%）；③ 合约单位 默认按品种查表（缺失则 10，仅全局缩放，不改变 Flip 价位与形态）。 抓取失败时自动降级为 ATM 近似 + IV 20% 并在概览标注。
